Primary developer

HyPar

A conservative finite-difference solver for n-dimensional hyperbolic-parabolic partial differential equations on Cartesian grids, written in C with MPI. Several physical models are included (linear advection-reaction-diffusion, Euler and Navier-Stokes equations, Fokker-Planck models for power systems) and others can be added. Spatial discretizations include MUSCL, WENO, CRWENO, and compact central schemes; time integration uses built-in Runge-Kutta methods or the PETSc TS module. CUDA support is available for selected models.

Dependencies: MPI (a serial build is produced if absent); PETSc and CUDA optional.

EUCLID

A high-order conservative finite-difference code for multifluid plasma simulation, used for interpenetrating and counterstreaming plasmas in inertial-confinement-fusion applications. Written in C++. The methods are described in Ghosh et al., Computers and Fluids 186 (2019).

The repository is not public; contact me for access.

TridiagLU

Parallel (MPI) solvers for distributed tridiagonal and block-tridiagonal systems. The parallel LU solver uses iterative substructuring, with the reduced system solved either directly (gather-and-solve with LU) or iteratively (point Jacobi). Multiple independent systems are solved in a single call, which is what makes nonlinear compact reconstruction affordable at scale. A test suite measures solver wall times.

Dependencies: MPI (a serial build is produced if absent).
Documentation · Source

IBCartINS3D

A three-dimensional Cartesian incompressible Navier-Stokes solver with an immersed boundary technique. Based on the fractional-step method, with higher-order upwind reconstruction for convection and second-order central discretization for viscous and pressure-correction terms. Viscous terms are integrated implicitly and convection explicitly. The parallel version uses a three-dimensional Cartesian domain decomposition.

Dependencies: MPI (a serial build is produced if absent).
